# Telegram Website Monitor

A Telegram bot that monitors website changes and sends notifications when new content appears.

## Features

- Start and stop monitoring from Telegram
- Check a website every N minutes
- Detect website content changes
- Send Telegram notifications
- Store the last known website state
- Log errors and bot activity

## Technologies

- Python
- Aiogram
- Requests
- BeautifulSoup4
- python-dotenv

## Use Case

This bot can be used to monitor:
- product availability
- price changes
- new articles
- new job posts
- website updates
